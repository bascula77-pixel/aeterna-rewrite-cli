# Aeterna Rewrite Engine (CLI Open Core)

CLI-интерфейс локального движка глубокого смыслового рерайтинга и структурирования текста на базе квантованных языковых моделей.

## Архитектура (Open Core)

Проект построен по модульному принципу:
* **CLI Client (Open Core):** Открытый интерфейс командной строки для интеграции в локальные конвейеры, bash-скрипты и сторонние утилиты.
* **SynergyCore (Proprietary Engine):** Автономное оптимизированное ядро инференса на C/Python со встроенной многопроходной обработкой контекста. Поставляется в виде скомпилированного бинарного модуля без внешних облачных зависимостей.

## Использование CLI

```bash
# Базовый рерайт из файла
python3 main.py --file input.txt --output result.txt

# Рерайт через stdin
cat input.txt | python3 main.py --style "Художественный"

# Режим структурирования с выводом телеметрии в JSON
python3 main.py --file input.txt --mode "Структура" --json
```

### Параметры запуска

| Параметр | Значения | Описание |
|---|---|---|
| `--file`, `-f` | Путь к файлу | Входной текстовый файл (UTF-8) |
| `--output`, `-o` | Путь к файлу | Файл для сохранения результата |
| `--style`, `-s` | `Лёгкий`, `Углублённый`, `Художественный` | Стиль обработки текста |
| `--mode`, `-m` | `Рерайт`, `Структура` | Режим работы ядра |
| `--temperature`, `-t` | `0.1` - `1.0` | Температура генерации (по умолчанию `0.7`) |
| `--no-synergy` | Флаг | Отключение многопроходной обработки контекста |
| `--json` | Флаг | Вывод результата и метаданных в формате JSON |
